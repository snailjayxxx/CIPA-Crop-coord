# CIPA Crop & Coord v6.2.0 — 稳定版 / 安定版 / Stable release

发布日期：2026-11-11  
**正式源码基线：** 用户在 Windows 上重启并复测确认可正常处理的 `70537e4b3ba8fcf3b49e318e08765b436ae69082`。  
**使用范围：** Windows 64-bit 单文件 EXE；包含图片裁切与 FindsBlur v1.3.1 还原计算核心，运行时无需安装 Python。

## 中文更新内容

- 将相似区域裁切与抖动量计算整合到同一个 EXE，可勾选“抖动量计算结果输出”自动计算并保存 TXT，裁切与计算线程各自配置。
- 成功裁切第 **4** 张照片后启动计算；如果仅有 1–3 张成功裁切，在裁切完成后继续计算。处理结果按原图片顺序输出。
- 可选 CalcDebug 中间结果，以及独立设置的 CalcDebug 文件夹。
- 默认日语界面，保留中文/英文切换；“匹配范围与精度”“输出设置”默认折叠，窗口按展开内容调整。
- 调整裁切与计算的线程控件和 Debug 复选框位置、浏览按钮宽度、裁切/计算两个“已处理张数/总张数”进度条；处理记录窗口约 9 行并可滚动。
- 选择遍历文件夹后，自动建议其内部 `resize` 文件夹为裁切输出；原有 `FindsBlur_Result.txt` 的自动填写规则保留，可手工修改保存位置。
- 保留其余六个功能页以及既有图像处理参数、保存文件名及图像质量设置。

**版本选择：** 本次按用户实际 Windows 复测通过的版本发布。后来追加“内存预算/高并发自动限流/崩溃日志”的实验安全版**不包含在 v6.2.0**，已单独保留于 `safety/memory-guard-20261111`（`25e5c596`）。

**验证说明：** 本版通过自动测试、集成 Windows 构建和打包程序的自检；用户也已在重启后的 Windows 环境复测正常。尚未完成与商业官方 FindsBlur EXE 对所有 110/113 张参考照片的逐项数值一致性认证。

## 日本語

- 切り抜きと FindsBlur v1.3.1 のブレ量計算を 1 本の EXE に統合しました。
- 4 枚の切り抜き保存完了後に計算を開始。成功画像が 1～3 枚の場合は、切り抜き終了後に計算します。
- 切り抜き用/計算用スレッド数を独立して指定でき、CalcDebug の保存先も指定可能です。
- 起動時は日本語表示。中国語・英語への切り替え、詳細設定の折りたたみ、文字が欠けない参照ボタン、枚数表示の進捗バー、約 9 行のスクロール可能なログに対応。
- 対象フォルダーを選択すると、切り抜き保存先にその直下の `resize` を自動提案します。TXT の既存命名方式は維持します。
- **この正式版には**実験段階のメモリ保護機能を含めず、独立した安全対策ブランチとして保管しています。
- ご利用者による Windows 動作確認と CI のテストは通過済みですが、公式 FindsBlur との全画像数値比較は未完了です。

## English

- Integrated similar-region image cropping and reconstructed FindsBlur v1.3.1 calculation into one Windows EXE.
- Calculation begins after four successful crops; batches of one to three successful crops are calculated after cropping completes.
- Independent crop/calculation worker counts, optional CalcDebug output, Japanese default interface with Chinese/English options.
- Collapsible advanced settings, responsive browsing controls, count-based crop/calculation progress, nine-line scrollable log and automatic `resize` crop output suggestion.
- The later experimental high-concurrency memory guard is **not included** in this release; its source is preserved separately on `safety/memory-guard-20261111`.
- Passed Windows CI and integrated EXE self-tests; user confirmed the preceding tested version works after reboot. Numerical identity with every result of the official FindsBlur EXE remains unverified.
