## Windows 下载与运行

下载下方的 **CIPA-Crop-Coord.exe**，双击即可运行，无需安装 Python。适用于 64 位 Windows。

本次正式发布沿用已验证补丁版的版本名称，将其规范为 **v6.1.0**。程序包含六个功能页，支持中文、日语和英语。

## 新增：图片生成视频

- 将所选文件夹本层的图片按文件名自然顺序生成 MP4，例如 `1.png`、`2.png`、`10.png`。
- 可设置每秒图片数，默认 **10 张/秒**。
- 可设置视频总帧数；`0` 表示使用全部图片。设定数较少时截断，较多时在末尾补黑屏。
- 不同尺寸图片等比例缩放并补黑边，视频尺寸以第一张可读取图片为准。
- 保存位置支持 MP4 文件路径或已有文件夹路径；已有视频在确认后才替换。

## 修复与语言支持

- 修复生成视频时报 `'function' object has no attribute 'is_set'` 的问题。
- 支持中文、日文路径及跨盘保存。
- 取消或写入失败时保留原文件，并清理临时文件。
- 补齐新增页中、日、英三种语言的界面、参数校验、编码错误、覆盖确认和进度提示。
- 保留相似区域裁切、中心裁切、三模式坐标导出、图片压缩及视频逐帧导出功能。

## 検証済みの主な変更

- 画像から MP4 を作成する6番目のタブを追加。FPS と総フレーム数を指定でき、不足分は黒画面で補完します。
- キャンセル時のエラー、保存フォルダー指定、別ドライブへの保存を修正しました。
- 中国語・日本語・英語の表示とメッセージに対応しています。
- **CIPA-Crop-Coord.exe** をダウンロードして実行してください。Python のインストールは不要です。
